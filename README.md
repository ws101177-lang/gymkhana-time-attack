# 짐카나 타임어택

포뮬러 스튜던트 차량(YUSAE YF-25)으로 달리는 3인칭 3D 웹 레이싱 게임입니다. F1 중계 화면 느낌으로 꾸몄습니다.
HTML 파일 하나와 Three.js(CDN)로 만들었고, 이미지·소리 파일은 쓰지 않았습니다(텍스처와 소리 모두 코드로 생성).

## 트랙

| 트랙 | 내용 |
|---|---|
| A · 짐카나 | 2024 오토크로스-짐카나 콘 코스 1바퀴 (약 0.5km) |
| B · 시가지 서킷 | 모나코·싱가포르 느낌의 시가지 서킷 3바퀴 (한 바퀴 약 1.19km). 폭 7m 도로 양옆이 바로 방호벽, 좁은 헤어핀·시케인·터널 |

## 기능

- 메인 화면: 차고 쇼룸에서 차를 3D로 돌려 보고(끌어서 회전), 차 색상 10가지 + 직접 고르기, 트랙·낮/밤·소리 설정
- 출발: F1식 빨간불 5개가 하나씩 켜지고(삐 소리) 한꺼번에 꺼지면 출발. 대기 중 가속 키로 엔진을 띄울 수 있음
- 계기판: 가로 회전수 막대(찰수록 흰색→노랑→주황→빨강, 끝까지 차면 계기판 전체가 빨강/보라로 깜빡임), 속도, 기어와 다음 기어, 페달 막대
- 차량: 단면을 이어 만든 곡면 차체(YEF-24 도색), 날개 단면, 둥근 슬릭 타이어, 배기구. 감속하면 백파이어 불꽃과 소리
- 그래픽: PC에서는 블룸(불빛 번짐) 후처리
- 기록판(왼쪽 위): 랩, 시간, 베스트 랩, 지난 랩, 콘 감점, 고스트 대비 시간(초록/빨강, 개인 최고 랩은 보라)
- 미니맵(오른쪽 위), 화면 UI 끄기
- 밤 모드: 별·달, 조명탑, 광고판 LED, 도시 불빛, 관중 응원봉이 빛남
- 관중: 응원봉을 흔들고 점프하며, 차가 가까이 오면 더 들썩이고 환호 소리도 커짐
- 소리: 엔진(회전수 따라 음높이), 타이어, 잔디, 바람, 관중, 출발 신호, 코드로 만든 배경음악. 내 기기의 음악 파일을 배경음악으로 고를 수 있고, 한 번 고르면 브라우저에 기억됨(업로드하지 않음)
- 물리: 평소 그립 주행(기구학 자전거 모델, 횡가속 1.6g), Space를 누르는 동안 타이어 슬립각·하중 이동·마찰원을 계산하는 드리프트
- 고스트: 트랙마다 가장 빠른 주행을 이 브라우저에 저장해 다음 판에 같이 달림
- 기기 성능에 따라 해상도와 그림자 품질을 자동으로 낮춰 휴대폰에서도 부드럽게 동작

`index.html`을 브라우저로 열면 됩니다(인터넷 연결 필요: Three.js와 글꼴을 CDN에서 불러옴).
