# 짐카나 타임어택

포뮬러 스튜던트 차량(YUSAE YF-25)으로 2024 오토크로스-짐카나 코스를 달리는 3인칭 3D 웹 게임입니다.
HTML 파일 하나와 Three.js(CDN)로 만들었고, 이미지 파일은 쓰지 않았습니다.

## 조작

| 동작 | PC | 휴대폰 |
|---|---|---|
| 가속 / 브레이크·후진 | ↑ / ↓ | ▲ / ▼ |
| 조향 | ← → | ◀ ▶ |
| 드리프트 (누르는 동안) | Space | DRIFT |
| 시점 전환 | C | 시점 |
| 코스 복귀 | B | 복귀 |
| 다시 하기 | R | 다시 |

## 규칙

- 3-2-1 카운트다운 뒤 출발선을 지나면 기록이 시작됩니다.
- 체크포인트 35개를 순서대로 지나 도착선을 통과하면 완주입니다.
- 콘에 닿으면 1개당 +2초. 최종 기록이 낮을수록 좋습니다.
- 완주 기록 중 가장 빠른 주행이 고스트로 저장되어 다음 판에 같이 달립니다.

## 만든 방식

- 평소에는 미끄러지지 않는 그립 주행(기구학 자전거 모델, 횡가속 1.6g 한계)
- Space를 누르는 동안에는 타이어 슬립각·하중 이동·마찰원·다운포스를 계산하는 동역학 모델로 드리프트
- 기기 성능에 따라 해상도와 그림자 품질을 자동으로 낮춰 휴대폰에서도 부드럽게 동작

## 실행

`index.html`을 브라우저로 열면 됩니다(인터넷 연결 필요: Three.js를 CDN에서 불러옴).
