# Racing Arcade (짐카나 타임어택)

포뮬러 스튜던트 차량(YUSAE YEF-24)으로 달리는 3인칭 3D 웹 레이싱 게임입니다. F1 중계 화면 느낌으로 꾸몄습니다.
HTML 파일 하나와 Three.js(CDN)로 만들었고, 이미지·소리 파일은 쓰지 않았습니다(텍스처와 소리 모두 코드로 생성).

## 트랙

| 트랙 | 내용 |
|---|---|
| A · 짐카나 | 2024 오토크로스-짐카나 콘 코스 1바퀴 (약 0.5km) |
| B · 모나코 시가지 | 모나코 서킷을 줄여 옮긴 시가지 서킷 3바퀴 (한 바퀴 약 0.64km). 폭 7m 도로 양옆이 바로 방호벽. 그랜드 호텔 헤어핀, 터널, 누벨 시케인, 수영장 S자, 라스카스 |

## 모드

| 모드 | 내용 |
|---|---|
| 타임어택 | 혼자 달려 기록 경신. 가장 빠른 주행이 고스트로 같이 달림 |
| 토너먼트 (짐카나) | 대회 규정처럼 같은 코스 두 개(코스1 · 배리어 · 코스2)에서 상대와 동시에 출발. 8명이 8강 → 4강 → 결승. 파일런 1개당 +1초, 규정 점수 공식 표시 |
| AI 레이스 8대 | 모나코 서킷에서 AI 7대와 함께 그리드 출발, 3바퀴. 실시간 순위표, 차끼리 부딪힘 |
| 온라인 | 닉네임을 정하고 방 만들기/방 찾기. 초대 링크(`?room=코드`)로 들어온 사람끼리 최대 8명이 함께 레이스 |

온라인은 별도 게임 서버 없이 공개 MQTT 중계 서버 두 곳(EMQX, HiveMQ)에 웹소켓으로 동시에 붙어 메시지를 주고받습니다. 휴대폰 데이터·와이파이 어디서든 연결됩니다.

## 기능

- 메인 화면: 레이싱 게임 차고 화면처럼 어두운 스튜디오에 큰 차(끌어서 회전), 오른쪽 제원표, 아래쪽 도색 카드(도색마다 실제 3D로 찍은 사진), 트랙·낮/밤·소리 설정
- 출발: F1식 빨간불 5개가 하나씩 켜지고(삐 소리) 한꺼번에 꺼지면 출발. 대기 중 가속 키로 엔진을 띄울 수 있음
- 계기판: 가로 회전수 막대(찰수록 흰색→노랑→주황→빨강, 끝까지 차면 계기판 전체가 빨강/보라로 깜빡임), 속도, 기어와 다음 기어, 페달 막대
- 차량: 실차 사진 기준으로 다시 만든 YEF-24. 높고 둥근 총알형 노즈(흰 테두리·파란 줄), 노즈 옆 YUSAE, 흰·파란 줄 사이드포드, 파랑·흰 프론트윙 옆판, YEF-24 리어윙, 금색 휠 센터, 흡기 스노클, 은색 머플러. 감속하면 백파이어 불꽃과 소리
- 그래픽: PC에서는 블룸(불빛 번짐) 후처리
- 기록판(왼쪽 위): 랩, 시간, 베스트 랩, 지난 랩, 콘 감점, 고스트 대비 시간(초록/빨강, 개인 최고 랩은 보라)
- 미니맵(오른쪽 위), 화면 UI 끄기
- 밤 모드: 별·달, 조명탑, 광고판 LED, 도시 불빛, 관중 응원봉이 빛남
- 관중: 응원봉을 흔들고 점프하며, 차가 가까이 오면 더 들썩이고 환호 소리도 커짐
- 소리: 엔진(회전수 따라 음높이), 타이어, 잔디, 바람, 관중, 출발 신호, 코드로 만든 배경음악. 내 기기의 음악 파일을 배경음악으로 고를 수 있고, 한 번 고르면 브라우저에 기억됨(업로드하지 않음). 내 컴퓨터에서 실행할 때 `index.html` 옆에 `bgm.mp3`가 있으면 자동으로 배경음악이 됨(저장소에는 올리지 않음)
- 물리: 평소 그립 주행(기구학 자전거 모델, 횡가속 1.6g), Space를 누르는 동안 타이어 슬립각·하중 이동·마찰원을 계산하는 드리프트
- 고스트: 트랙마다 가장 빠른 주행을 이 브라우저에 저장해 다음 판에 같이 달림
- 최적화: 차 부품을 재질별로 합쳐 그리기 호출을 줄임(차 한 대 약 200 → 48 메시, 고스트는 1개), 관중은 낮은 다각형·휴대폰은 60%만, 화면 밀도 상한 1.5배, 경기장 전체에 퍼진 물체는 그림자 계산에서 빼고, 관중 움직임은 30Hz로 갱신. 프레임이 50 아래로 떨어지면 블룸 → 해상도 → 그림자 순으로 자동으로 낮춤
